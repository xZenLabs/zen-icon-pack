# Zen UI — Default Light

The recommended Zen UI icon pack. It uses
[Material Design Light](https://icon-sets.iconify.design/mdi-light/) as its
visual base, with a small number of rounded outline icons from
[Material Symbols Light](https://icon-sets.iconify.design/material-symbols-light/),
[Material Design Icons](https://icon-sets.iconify.design/mdi/), and
[Ionicons](https://icon-sets.iconify.design/ion/) where they communicate a Zen
UI action more clearly.

The Navbar receives the most deliberate treatment: Home uses the official
`mdi-light:home`, Authors uses the single-person `mdi-light:account`, and
Library uses Ionicons' light outlined stack of upright and leaning books. All
artwork is sourced through [Iconify](https://icon-sets.iconify.design/) on a
normalized 24px canvas with an explicit black color for reliable e-ink
rendering.

Copy this folder or its ZIP into KOReader's `icons/zen` directory. Enable
**Zen UI > Extras > Allow custom icons**, select **Zen UI — Default Light**,
and restart KOReader.

See `LICENSE-ICONS.txt` for upstream licenses. Exact collection and icon names
are maintained in the repository's `icon-mappings.json`.
