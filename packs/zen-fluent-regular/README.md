# Zen UI — Fluent Regular

This pack replaces the 71 canonical Zen UI icons with the Regular style from
[Fluent UI System Icons](https://icon-sets.iconify.design/fluent/), provided
through Iconify. It uses 24px variants except where a semantic icon is only
available at 20px.

Copy this folder or its ZIP into KOReader's `icons/zen` directory. Enable
**Zen UI > Extras > Allow custom icons**, select **Zen UI — Fluent Regular**,
and restart KOReader.

See `LICENSE-ICONS.txt` for the upstream icon license. Exact source-icon
mappings are maintained in the repository's `icon-mappings.json`.
