# Zen UI — Phosphor Regular

This pack replaces the 62 canonical Zen UI icons with the Regular style from
[Phosphor](https://icon-sets.iconify.design/ph/), provided through Iconify.

Copy this folder or its ZIP into KOReader's `icons/zen` directory. Enable
**Zen UI > Extras > Allow custom icons**, select **Zen UI — Phosphor Regular**,
and restart KOReader.

See `LICENSE-ICONS.txt` for the upstream icon license. Exact source-icon
mappings are maintained in the repository's `icon-mappings.json`.
