# Zen icon catalog

Category folders sit directly beside each style's `pack.json`.
Quick settings belong in `controls/`; left/right page tabs belong in `navbar/`.
Zen page-browser icons belong in `reader/`. Stock icons and book_open stay in `koreader/`.
Release ZIPs flatten the categories into the pack root.

| Category | Contents |
|---|---|
| [navbar](#navbar) | Library, reading lists, Navbar tabs, and left/right page tabs. |
| [lookup](#lookup) | Highlight, dictionary, vocabulary, search, and AI lookup actions. |
| [launcher](#launcher) | Highlight style, color, and delete controls. |
| [zenpm](#zenpm) | Annotation filtering and sorting. |
| [reader](#reader) | Pins, footnotes, and return navigation. |
| [settings](#settings) | ZenOS settings menu rows, mirroring ZenOS's bundled `settings_*` lookups. |
| [koreader](#koreader) | Stock KOReader icons, including appbar, plus/info, bookmarks, and book_open. |
